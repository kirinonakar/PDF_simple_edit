# Native text style regression checks

Run on Windows with the .NET 10 SDK and the standard Arial, Times New Roman,
and Malgun Gothic fonts installed:

```powershell
dotnet run --project tests/NativeTextStyles/NativeTextStyles.csproj
```

The checks generate their own PDFs and verify font, size, color, bold/italic,
partial and multiple selections, shared Form isolation, Korean italic fallback,
text-state restoration, overlap rejection, and paragraph reflow. They reopen
the generated bytes and render sample pages with Windows.Data.Pdf, the app's
preview renderer. Fixtures and PNGs are written to `output/pdf/native-styles`.
An optional first argument overrides the output directory.
